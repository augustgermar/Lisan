YourWeb cPanel skill

Read-first, approval-gated procedures for inspecting and administering YourWeb cPanel accounts through Codex or ChatGPT.

Download the skill package Read SKILL.md

Give this URL to a fresh Codex install

Send Codex this page URL and ask it to install the yourweb-cpanel skill from the linked package:

https://acgermar.yourweb.csuchico.edu/skills/

Codex should download yourweb-cpanel-skill.zip, extract the yourweb-cpanel directory, and place it in the active skills directory or the repository’s .agents/skills/ directory. Then ask it to use $yourweb-cpanel.

What is included

  • SKILL.md with the current operating sequence and safety rules
  • scripts/yourweb_cpanel.py for deterministic cPanel API and public verification checks
  • references/source-guide.md with the detailed YourWeb operating guide
  • agents/openai.yaml metadata for compatible tooling

Credential setup

The skill reads credentials from the local environment or secret store. Set YOURWEB_CPANEL_HOST, YOURWEB_CPANEL_USER, and YOURWEB_CPANEL_TOKEN (compatible CPANEL_* names are also accepted). Never put the token in chat or logs.

Scope

It covers domain discovery, file and document-root checks, mailbox inventory, AutoSSL inspection, DNS/HTTP/TLS verification, and carefully controlled cPanel operations. Writes require explicit approval and separate verification.
